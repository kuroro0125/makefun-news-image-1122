One page that sums up Sunday 22 November 2026: a Brazilian town digging
out after a deadly storm, Nvidia facing a US accounting probe, Iran
striking three tankers, and Trump's pledge to cap credit card interest
at 10% — plus a five-line ALSO TODAY strip (Peru's 6.7 quake, the
Rohingya genocide verdict, Pentagon–Canada ties, South Korea's AI race,
the COP31 deadlock).

`entry.png` is rendered by `render.py` (Pillow, deterministic — same
bytes on every run) from that day's wire and newspaper headlines (AFP,
AP, Reuters). `main.py` copies the bundled sheet into the output
directory the harness points at.

## Run it

```sh
python3 main.py
```
